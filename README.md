# โปรแกรมช่วยเทรดหุ้น (Stock Trader)

สแกนหุ้นไทย/อเมริกา → ให้คะแนน 0–100 → บอก **ซื้อ / รอจังหวะ / หลีกเลี่ยง** พร้อมจุดเข้า, Stop, เป้า และจำนวนหุ้นที่ควรซื้อ
มีระบบทดสอบย้อนหลัง (backtest), พอร์ตจำลอง (paper trading) และรายงาน HTML

## เริ่มใช้งาน (ง่ายสุด)
1. ดับเบิลคลิกไอคอน **หุ้นเด่น** บนหน้าจอ (หรือ `dist\StockTrader.exe`) — ข้อมูลเก็บในโฟลเดอร์ `dist\data`
2. โปรแกรมเปิดเป็นหน้าต่างของตัวเอง ไม่มีหน้าต่าง command
3. ปิดหน้าต่างได้ตามปกติ โปรแกรมยังทำงานอยู่ที่ **ไอคอนมุมขวาล่าง** (ข้างนาฬิกา อาจซ่อนอยู่ใต้ปุ่ม ^) เพื่อให้มือถือเข้าได้
   - คลิกไอคอน = เปิดหน้าต่างอีกครั้ง · คลิกขวา → **ปิดโปรแกรม** = ปิดจริง
   - ดับเบิลคลิกซ้ำขณะเปิดอยู่ จะแค่เปิดหน้าต่างใหม่ ไม่เปิดโปรแกรมซ้อน
4. ถ้า Windows ถามเรื่อง Firewall → กด **Allow / อนุญาต** (เครือข่ายส่วนตัว) เพื่อให้มือถือเข้าได้

### ใช้บนมือถือ
- มือถือต้องต่อ **WiFi เดียวกับคอมพิวเตอร์** และคอมพิวเตอร์ต้องเปิดโปรแกรมค้างไว้
- สแกน QR code ในแท็บ **ตั้งค่า** (หรือคลิกขวาไอคอนมุมขวาล่าง → "เปิดบนมือถือ") (มี PIN 6 หลักกันคนอื่นใน WiFi เดียวกัน)
- iPhone: Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม" / Android: Chrome → ⋮ → "เพิ่มลงในหน้าจอหลัก"
  แล้วจะได้ไอคอน "หุ้นเด่น" ใช้เหมือนแอป (ครั้งแรกที่เปิดจากไอคอนอาจต้องใส่ PIN อีกครั้ง)

### เว็บแอปมีอะไรบ้าง
| แท็บ | ทำอะไร |
|---|---|
| หุ้นเด่น | สภาพตลาด + รายชื่อหุ้น ซื้อ/รอจังหวะ/หลีกเลี่ยง (ไทย/อเมริกา) กดปุ่ม ⟳ เพื่อดึงราคาล่าสุด |
| วิเคราะห์ | ค้นหาหุ้นรายตัว: กราฟ + เส้น Stop/เป้า, คะแนน, แผนเทรด, อินดิเคเตอร์, งบการเงิน, ผลย้อนหลัง |
| พอร์ต | พอร์ตจำลอง: ซื้อ/ขาย, Stop เลื่อนอัตโนมัติ, เตือนเมื่อควรขาย |
| ย้อนหลัง | Backtest ทั้งพอร์ต เทียบกับดัชนี, ผลรายปี, รายการเทรด |
| ตั้งค่า | เงินทุน, % เสี่ยงต่อไม้, QR code สำหรับมือถือ |

หุ้นอเมริกาคำนวณจำนวนหุ้นจากเงินทุนบาทโดยแปลงด้วยอัตรา USD/THB ล่าสุด

### สร้าง .exe ใหม่ (หลังแก้โค้ด)
ดับเบิลคลิก `build_exe.bat` → ได้ไฟล์ใหม่ที่ `dist\StockTrader.exe`

## ใช้แบบคำสั่ง (ทั้ง .exe และ Python)
```
StockTrader.exe scan               (หรือ python main.py scan)
python main.py report              # หรือดับเบิลคลิก run_report.bat
```

| คำสั่ง | ทำอะไร |
|---|---|
| `python main.py web` | เปิดเว็บแอป (เหมือนดับเบิลคลิก .exe) |
| `python main.py scan` | สแกนหุ้นไทย 70 ตัว (`--list us` = หุ้นอเมริกา, `--tickers PTT AOT` = ระบุเอง) |
| `python main.py analyze PTT` | วิเคราะห์รายตัวละเอียด + backtest ตัวนั้น |
| `python main.py backtest` | ทดสอบกลยุทธ์ย้อนหลัง 10 ปีทั้งพอร์ต (`--years 5`) |
| `python main.py report` | สแกน + backtest + เปิดรายงาน HTML |
| `python main.py paper buy PTT` | ซื้อในพอร์ตจำลอง (คำนวณจำนวนหุ้นให้) |
| `python main.py paper status` | อัปเดตพอร์ตจำลอง เลื่อน Stop และเตือนจุดขาย |
| `python main.py paper sell PTT` / `paper reset` | ขาย / เริ่มพอร์ตใหม่ |

ตั้งค่าเงินทุน ความเสี่ยงต่อไม้ และรายชื่อหุ้นได้ที่ `config.py`

## หลักการที่ใช้
**คะแนนรวม 100** = เทคนิค 75 + พื้นฐาน 25
- **แนวโน้ม (30)** — ราคา > SMA200, SMA50 > SMA200, เส้น 200 วันชี้ขึ้น, ใกล้ไฮ 52 สัปดาห์
- **โมเมนตัม (25)** — ผลตอบแทน 3/6/12 เดือนเทียบหุ้นอื่น, RSI 50–68, MACD, ADX
- **วอลุ่ม (10)** — OBV ขึ้น (มีเงินไหลเข้า), วอลุ่มหนุนวันขึ้น
- **ความผันผวน (10)** — ATR ต่ำ, ไม่ยืดเกินกรอบ Bollinger
- **พื้นฐาน (25)** — P/E, P/BV, ROE, ปันผล, หนี้สิน/ทุน, การเติบโตรายได้, อัตรากำไร

**จังหวะซื้อ** (ต้องอยู่ในขาขึ้นก่อนเสมอ และ RSI < 75)
1. **ย่อแล้วเด้ง** — RSI ลงต่ำกว่า 45 แล้วราคากลับขึ้นเหนือ EMA20
2. **เบรกเอาต์** — ทะลุไฮ 55 วัน วอลุ่ม > 1.5 เท่า ADX > 20
3. **MACD ตัดขึ้น** — ในขาขึ้นและ RSI < 65

**จังหวะขาย**
- Stop เริ่มต้น = ราคาเข้า − 2×ATR
- Trailing stop = ราคาปิดสูงสุด − 3×ATR (เลื่อนขึ้นอย่างเดียว)
- หลุดเส้น 200 วัน → ขาย
- ถึงเป้า 2R → ขายครึ่งหนึ่ง ปล่อยที่เหลือวิ่งตาม trailing stop

**คุมความเสี่ยง** — เสี่ยงไม่เกิน 1% ของพอร์ตต่อไม้, ถือตัวละไม่เกิน 20%, ไม่เกิน 6 ตัว,
ไม่ซื้อใหม่เมื่อตลาด (TDEX/SET50) อยู่ใต้เส้น 200 วัน, ตัดหุ้นที่มูลค่าซื้อขาย < 20 ล้านบาท/วัน

## ผลทดสอบย้อนหลัง (หุ้นไทย 70 ตัว, ก.ย. 2017 – พ.ย. 2026, ทุน 100,000)
| | กลยุทธ์ | ซื้อ SET50 (TDEX) ถือไว้ |
|---|---|---|
| ผลตอบแทนรวม | **+65.8%** (5.7%/ปี) | +41.2% |
| ขาดทุนสูงสุดจากจุดสูงสุด | **−21.1%** | −36.5% |
| อัตราชนะ | 37.5% (ชนะเฉลี่ย +12.3%, แพ้เฉลี่ย −4.0%) | |

ข้อจำกัด: ใช้รายชื่อหุ้นปัจจุบัน (survivorship bias), ไม่มีข้อมูลพื้นฐานย้อนหลัง, ข้อมูล Yahoo อาจคลาดเคลื่อน — ผลจริงมักแย่กว่าผลทดสอบ

## วิธีใช้ที่แนะนำ
1. รัน `report` หลังตลาดปิด (หลัง 17:00)
2. เลือกเฉพาะหุ้นสถานะ **ซื้อ** ที่เข้าใจธุรกิจ ส่งคำสั่งซื้อช่วงเปิดตลาดวันถัดไป และตั้ง Stop ในแอปโบรกทันที
3. หุ้น **รอจังหวะ** = จดราคาโซนย่อ/จุดเบรกไว้ ตั้งแจ้งเตือนราคาในแอปโบรก
4. รัน `paper status` ทุกวันเพื่อเลื่อน Stop
5. ฝึกกับพอร์ตจำลองอย่างน้อย 2–3 เดือน ก่อนใช้เงินจริง

> ไม่ใช่คำแนะนำการลงทุน — การลงทุนมีความเสี่ยง ผลในอดีตไม่รับประกันอนาคต
